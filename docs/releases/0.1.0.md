# Sourcebook 0.1.0

*2026-10-11 · the first version: a local, single-user notebook of modular blocks, with an MCP server for AI assistants.*
*(Version number assigned afterwards: 0.1.0 is the state of the repository up to commit `daeb947`.)*

## Highlights
- **A notebook of modular blocks**: projects made of a tree of sections, each holding ordered, typed sub-blocks, saved
  as plain files (Markdown first) in a workspace folder.
- **An MCP server**: AI assistants (Claude Code, Claude Desktop, any MCP client) read and edit projects with you —
  sections, blocks, lines, comments, references, bibliography — and tell you what they changed.
- **References readable by the assistant**: PDFs, Office documents, e-mails and more converted to Markdown locally.

## Projects and templates
- Home page with projects and templates: create, rename, duplicate, delete; new project from a template; save a
  project as a template.
- Templates exported and imported as ZIP files, validated before import (with a preview).
- Example templates created by a script: **Software Project** (prompts and instructions for the assistant,
  requirements, open questions, decisions as ADR with status, architecture, design, data models, testing, plan,
  issues), **Scientific Paper**, **Research Project Proposal**, **Thesis**.

## Editor
- Outline of sections (§1, §2.1 …) with drag and drop to reorder and nest; sub-blocks (§2.1#3) reordered by dragging.
- **Objectives** on sections and sub-blocks: what each part must contain.
- Sub-block types: **Markdown** (rich text editor: tables, code, images, links), **Mermaid** diagrams, **drawings**
  (Excalidraw), **equations** (LaTeX / KaTeX), **code** (CodeMirror, any language, saved with its real extension),
  **images**, **questions** (question and answer), **multiple choice** (single or multiple, with a note).
- Diagrams and drawings exported as PNG / SVG next to their source.
- Links to sections, sub-blocks and comment threads that survive moving things (ids in the URL).
- Live updates: changes made by the assistant or another tab appear immediately; conflicting edits are detected.
- Export of the whole project as one Markdown document, or a ZIP with every referenced file.
- Appearance: light, dark, sepia and midnight themes, or following the system.

## Comments
- Comment a whole sub-block, a quoted passage of text or a range of code lines; replies, resolve and reopen.
- Comments follow their text when it moves, and show as detached when it is gone.
- Comments column next to the document, and a list of every thread of the project.

## Notifications and reload requests
- Applications and assistants notify the user of a group of changes: a summary plus links to the sections,
  sub-blocks or comments involved; unread count, mark as read, clear.
- Reload requests: at the end of a piece of work, open editors are asked to reload (pending edits are saved first).

## References
- A per-project folder of input files with folders, upload (drag and drop), rename, delete, download as ZIP, grid
  and list views, and viewers for common formats.
- Files linked from Markdown text or **attached** to a whole section or sub-block.
- **Automatic conversion to Markdown for the assistant**, locally in Node: PDF, Word (`.docx`, `.doc`), PowerPoint,
  Excel, OpenDocument, RTF, EPUB, HTML, Jupyter, e-mail (`.eml`, `.msg`), ZIP — in a background worker, split by
  page / slide / sheet / chapter.
- PDF analysis: scanned or drawn pages rendered as images; **figures cut out with their captions**; transcriptions
  of scanned pages saved by the assistant.
- "Assistant ready" status per file and a view of exactly what the assistant receives.
- Images and PDF figures inserted into image sub-blocks, with the source file attached.

## Bibliography
- Citable sources (articles, books, conference papers, web pages, software, data sets…) with BibTeX import and
  export and generated text citations.
- Citations in Markdown (`[Name](bib:key)`) and sources associated with sections or sub-blocks; the export adds a
  References section; renaming a key updates every citation.

## AI assistant (MCP)
- MCP server over **stdio** and over **HTTP** (built into the Sourcebook server, local requests only).
- Tools to read (outline, sections, sub-blocks with numbered lines, whole document, search, references with pages and
  figures, comments, notifications), write (projects, templates, sections, sub-blocks, atomic text edits, moves,
  images from references), discuss (comments, replies, re-anchoring, resolution), report (`notify_changes`,
  `request_reload`), manage references and the bibliography; destructive tools ask first.
- Prompts: review a section, fill placeholders, discuss comments.
- **Ask AI** button on the document, sections, sub-blocks, selections, comment threads and reference files: a
  ready-to-paste request (brainstorming, critique, build, improve, comment, or your own).
- Settings → AI assistant (MCP): enable or disable each transport, read-only mode, ready-made connection commands.

## Under the hood
- TypeScript monorepo: React + Vite client, Fastify server, shared zod schemas, MCP server package.
- REST API for everything the editor does (documented in the README), usable by scripts.
- Requirements: Node.js ≥ 22 and pnpm.
