# Screenshots

Sourcebook in use, on a test installation with fictitious people (Alex Morgan, Sam Rivera, Lena Novak) and agents
(Writer, Reviewer, Data analyst). The project shown is a copy of the **Sourcebook Demo** template that every new
installation contains.

### Projects

The home page: every project you can open, with the template it started from. Owners and users who may create projects start new ones here.

## Writing with blocks

### The editor

The outline of sections on the left (numbered §1, §2.1 …), typed sub-blocks on the right. Each section and block has an objective: what it must contain, for you and for the agents.

[![The editor](../images/screenshots/03-editor.webp)](../images/screenshots/03-editor.webp)

### Mermaid diagrams

Diagrams written as text and rendered live: flowcharts, sequence, class, state and ER diagrams.

[![Mermaid diagrams](../images/screenshots/05-mermaid-diagrams.webp)](../images/screenshots/05-mermaid-diagrams.webp)

### Hand-made drawings

Excalidraw sketches for ideas that do not fit a diagram, exported as PNG with the document.

[![Hand-made drawings](../images/screenshots/06-drawing.webp)](../images/screenshots/06-drawing.webp)

### Data sets

A CSV data set kept in the project: table, filters and sorting, and a summary of each column (type, empty cells, distinct values, min / max / mean, most frequent values).

[![Data sets](../images/screenshots/09-csv-column-summary.webp)](../images/screenshots/09-csv-column-summary.webp)

### Questions and decisions

Open questions with their answers, and decisions recorded as multiple choice with the reason for the choice.

[![Questions and decisions](../images/screenshots/10-questions-and-decisions.webp)](../images/screenshots/10-questions-and-decisions.webp)

## You decide, agents support

### Agents propose, you decide

A Reviewer agent comments a sentence; you answer and the Writer agent replies. Every message is signed by the agent and by the person it works for.

[![Agents propose, you decide](../images/screenshots/04-comments-on-text.webp)](../images/screenshots/04-comments-on-text.webp)

### Precise review and locks

A review comment on lines 8–11 of a code block. Below, the Python block is locked by the Writer agent: nobody else can change it until it is released — or until you unlock it.

[![Precise review and locks](../images/screenshots/07-code-review-and-lock.webp)](../images/screenshots/07-code-review-and-lock.webp)

### Reasoning on data

A Data analyst agent, working for another member of the team, comments individual rows of the data set.

[![Reasoning on data](../images/screenshots/08-csv-data-with-row-comments.webp)](../images/screenshots/08-csv-data-with-row-comments.webp)

### Nothing happens behind your back

Agents report what they changed: a summary and a link to each modified block. The changed sections are marked in the outline until you read the notification.

[![Nothing happens behind your back](../images/screenshots/11-agent-notifications.webp)](../images/screenshots/11-agent-notifications.webp)

### Every comment in one place

Open and resolved threads of the whole project, by section, with their authors.

[![Every comment in one place](../images/screenshots/12-all-comments.webp)](../images/screenshots/12-all-comments.webp)

### Ask AI

A scoped request about exactly one part of the project — a block, some lines, a comment thread — ready to paste into the assistant: brainstorming, critique, build, comment or your own prompt.

[![Ask AI](../images/screenshots/16-ask-ai.webp)](../images/screenshots/16-ask-ai.webp)

## People, agents and access

### Your agents, your rules

One personal access token configures the MCP connection once; each agent is a named identity of yours that you can make default, revoke or delete with everything it wrote.

[![Your agents, your rules](../images/screenshots/17-settings-agents.webp)](../images/screenshots/17-settings-agents.webp)

### Connecting an assistant

Ready-to-copy commands for Claude Code, Gemini CLI, OpenAI Codex and any other MCP client.

[![Connecting an assistant](../images/screenshots/18-settings-mcp.webp)](../images/screenshots/18-settings-mcp.webp)

### Users

The owner adds people with a temporary password, decides who may create projects, and can disable or reset accounts.

[![Users](../images/screenshots/19-settings-users.webp)](../images/screenshots/19-settings-users.webp)

### Access per project

Read (read and comment) or write access, project by project. Agents never have more rights than their person.

[![Access per project](../images/screenshots/20-settings-project-access.webp)](../images/screenshots/20-settings-project-access.webp)
